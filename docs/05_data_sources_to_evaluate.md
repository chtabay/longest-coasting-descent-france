# Data-source evaluation checklist

Do not select a source only because it is easy to access.

## Network data

Assess:

- national coverage;
- directed topology;
- bicycle permissions;
- road/path category;
- surface;
- barriers, ferries and access restrictions;
- intersection structure;
- geometry detail;
- update frequency;
- license and redistribution constraints.

Likely families to evaluate:

- OpenStreetMap-derived network;
- French national road/address/topographic open data;
- regional cycling datasets where useful.

## Elevation data

Assess:

- horizontal resolution;
- vertical accuracy;
- voids and artefacts;
- bridge/tunnel behavior;
- Corsica coverage;
- bulk download availability;
- license;
- reproducible versioning.

## Validation data

Potential families:

- public GPS traces with usable licensing;
- controlled coast-down measurements;
- published climb/descent profiles only as secondary checks;
- street-level imagery for manual audit, subject to access and terms.

## Required output

Create a comparison table with columns:

- source;
- role;
- coverage;
- resolution;
- known biases;
- access method;
- license;
- selected/rejected;
- reason.
